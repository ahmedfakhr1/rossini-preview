# Rossini website preview

A preview concept by Ahmed Fakhreldin for Rossini Restaurant, Almaza, Heliopolis. It is drawn from Rossini's public posts, menu and logo and is not an official Rossini site.

Static site: `index.html`, `menu.html`, `visit.html`, with `site.css` and `app.js`. Live at https://ahmedfakhr1.github.io/rossini-preview/.
